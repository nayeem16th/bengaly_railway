# Bengal Rail — National Journeys

A local React + JavaScript + Three.js student project, version 4.0.0.
Read START_HERE_BN.md for Windows/VS Code instructions.

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Open http://127.0.0.1:5173 while the terminal remains running.

Features: 24 selectable corridors, reverse direction, free exploration and coin-based career unlocks, passenger stops, engine/capacity upgrades, curved procedural track, detailed generated rolling stock, foliage cutouts, countryside, stations, rain/evening lighting, three cameras, physical lever UI, procedural audio, and quality settings.

All visual textures and geometry are generated by project code. No paid assets or map API keys are needed. The map uses approximate station coordinates and schematic corridor connections. Distances are compressed; this does not cover every Bangladesh station, actual service stopping pattern, or surveyed track alignment. It is not a photorealistic simulator.

Reference: Bangladesh Railway's published eastern and western timetables (Time Table 54, effective 10 March 2025), accessed during development. These are reference material, not a promise of current operating service:
- https://railway.gov.bd/pages/static-pages/691997bf933eb65569ddec51
- https://railway.gov.bd/pages/static-pages/691997b8933eb65569dde71d

Validation: npm test (11 game-rule tests, including every corridor in both directions); npm run build; node tests/scene-smoke.js (3D object construction with a stub canvas, not a render test).
The menu was verified in the browser, but the test browser disables WebGL, so gameplay rendering could not be visually verified. Check appearance and frame rate on the target laptop; start with Balanced or Low.

Dependencies and versions are pinned in package-lock.json. node_modules and build output are intentionally excluded from the source ZIP.


Edition 04 adds proportioned articulated people (hair, facial features, clothing variants, scarf/panjabi suggestions, bags), a pooled nearby platform crowd, staggered boarding/alighting, visible coach seating/passengers, physical cab fittings, procedural wheel/brake effects, device voice station announcements, station-specific inspired architecture, tea stalls, clocks, level-crossing barriers/cars, boats and utility poles.

Performance: platform crowd pool is 4/7/12 for Low/Balanced/High, coach seated passengers 1/2/4 per coach; static geometry is merged by material, repeated track/foliage is instanced, distant scenery is hidden, and sustained low measured FPS lowers resolution down to pixel ratio 0.7. Resolution recovers cautiously when the measured frame rate allows. FPS is visible during gameplay. No target-laptop benchmark has been performed; a fixed frame rate is not guaranteed. Low disables shadow maps.

Driving challenge: fictional limits are 70 km/h open track, 55 in rain, 35 within 150m of the next stop. A stop within 5m earns 40 coins (within 12m: 20); arriving within 55 active travel seconds earns 30; staying within limit + 2 km/h tolerance (less than 0.5s accumulated overspeed) earns 30. Missing a stop restarts the entire journey. Bonuses are credited with fares after boarding; Free Exploration earns no persistent coins. These are game rules, not real railway operating instructions.

Station voices depend on the browser/OS: Bengali when a Bengali voice exists, otherwise Bengali subtitles only; unavailable speech APIs leave announcements silent. Sound needs an initial click. Character models and station geometry remain lightweight procedural art, not scanned photorealistic assets. Windows are transparent and coach seating is visible; there is no walkable passenger cabin.

New source modules: src/world/people.js (articulated figures), details.js (station/scenery additions), optimize.js (static batching). No external model or audio asset downloads are needed.

## Edition 4.1 — Regional journeys
- Station-anchored city, industrial, town, village, tea, wetland and coastal scenery, including reverse travel. Artistic approximations, not surveyed land-use or track geometry.
- Passing an unserved stop by more than 24m deducts 100 journey points once; Career also deducts up to 100 wallet coins without a negative balance. Recovery preserves the deduction and forfeits the bonus. Exploration leaves wallet coins unchanged.
- Approach announcements, crossing warning bell, flashing lamps and waiting traffic. Speech remains dependent on OS voices; Bengali if available; otherwise Bengali subtitles.
- Clothing buttons, caps and spectacles added to procedural people.
- Tests: 14 game/region checks and geometry smoke; browser startup/interaction verification is recorded separately.

Edition 4.1 validation: 14 tests and scene smoke pass; production build passes. Browser menu opens; WebGL is disabled in the test browser, so gameplay and FPS remain unverified.

## Edition 4.2 — Bengali announcements and hard restart
Announcements never fall back to English. Bengali BD voices are preferred, then other Bengali voices; without a Bengali voice, the full Bengali announcement is shown on screen. Bundled generated speech could not be produced because the connected audio service requires a paid plan.
Passing a required station by more than 24m immediately restarts the same route/direction in both modes. Door recovery is removed. Current journey progress/bonus/earnings reset; career forfeits that attempt's credited earnings and 100 wallet coins, floored at zero. Previously purchased upgrades, unlocked routes, weather and quality remain. Exploration wallet is unchanged. This supersedes the Edition 4.1 missed-stop rule.
